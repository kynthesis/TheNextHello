# Music licenses

Keep original Mureka license files here, grouped by song using the same folder names as `assets/audio/music/`.

If one license covers both versions, store it directly in the song folder. If each version has its own license, use `a/` and `b/` subfolders. Preserve the original filenames and contents so the documents can be matched to the downloads.

The `.gdignore` file keeps this directory out of Godot's resource imports. Keep it in place.
